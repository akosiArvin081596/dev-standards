# Skip and focus markers: extended regexes (grep -E), case-sensitive, matched
# against ADDED lines of test files. An added line that matches fails the test
# guard, unless the identical line was removed in the same file (a moved line).

(^|[^A-Za-z0-9_.$])pending[[:space:]]*\(
